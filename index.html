☁️ Synchronisation Cloud (GitHub)

Connectez l'application à un dépôt GitHub privé pour que toutes les données (élèves, comptes, absences, caisse, etc.) soient partagées entre tous les appareils utilisés par votre équipe.

⚠️ Ce jeton n'est jamais fourni par Claude. Pour que la synchronisation fonctionne du premier coup, suivez cet ordre exact :

1. Créez d'abord le dépôt sur github.com → "New repository" → cochez "Add a README file" (important : un dépôt totalement vide fait échouer la synchro).
2. Seulement après, créez le jeton : Settings → Developer settings → Fine-grained tokens → Generate new token → "Repository access" → "Only select repositories" → choisissez CE dépôt → permission "Contents: Read and write".
3. Collez ci-dessus uniquement le nom d'utilisateur et le nom du dépôt (pas l'URL complète github.com/...).

Le jeton est enregistré uniquement dans le navigateur de cet appareil (localStorage), jamais dans le code de l'application. Ne partagez pas ce fichier HTML une fois le jeton saisi, et ne le publiez jamais dans un dépôt public.
